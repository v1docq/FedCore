# Инвентаризация external перед распространением

Проверены исходники, история Git и локальные уведомления на 05.10.2026. Это инвентаризация происхождения файлов, а не юридическое заключение. Полная внешняя лицензия не выводится из общего названия метода или статьи.

| Компонент | Локальное свидетельство | Лицензия и уведомления | Решение для внешнего исполнения |
|---|---|---|---|
| `external/transmlacore` | README называет минимальную переработку TransMLA; setup указывает FedCore Team. Последний предметный след истории: `b2b2cbd` | Отдельных LICENSE/NOTICE/COPYING в этом каталоге не найдено; точный upstream и перенесённая версия не подтверждены | Не импортируется вычислительным модулем; до отдельного распространения нужны источник, версия и требуемые уведомления |
| `external/flatllmcore` | README и история связывают код с FLAT-LLM; последний предметный след `513aaf9` | Отдельных LICENSE/NOTICE/COPYING не найдено. Ссылка на научную статью не подтверждает лицензию исходников | Не импортируется вычислительным модулем; происхождение и уведомления требуют отдельного подтверждения |
| `external/caracore` | Заголовок `cara.py` описывает Canonical Rank Adaptation; предметный след `21f70e0` | Отдельных LICENSE/NOTICE/COPYING не найдено; авторство/точный upstream в прочитанном файле не установлены | Не импортируется вычислительным модулем; отдельное распространение требует проверки происхождения |
| `tdecomp` | Используется установленная зависимость 0.2.18, без копирования её исходников в новый модуль | Метаданные зависимого пакета указывают BSD; подтверждение отдельных уведомлений остаётся у поставщика дистрибутива | Односторонняя зависимость FedCore; обратный импорт FedCore в tdecomp не добавлен |
| Новый `fedcore/external_runtime` | Новый код этого изменения; работает со стандартными слоями torch и исправленными компонентами FedCore | Действует LICENSE репозитория FedCore, BSD 3-Clause; новая внешняя лицензия не назначается | Не включает vendored-исходники трёх компонентов выше |

Корневой wheel полного FedCore по-прежнему может включать legacy `external`. Отдельный вычислительный путь не является подтверждением происхождения этих файлов и не отменяет проверку уведомлений перед их распространением. Текущий результат задачи #79 — явная граница исполнения, адаптеры и зафиксированный остаток происхождения; права на неизвестные внешние исходники не объявлены установленными.

Воспроизводимые команды проверки: `rg --files external`, поиск `LICENSE/NOTICE/COPYING`, поиск заголовков `license/author/github`, `git log -1 -- <component>`. Для обсуждения исходников следует использовать фиксированный базовый SHA `91e573462a01e77ef948a6e9175da5e736908359` и актуальный diff изменения.
