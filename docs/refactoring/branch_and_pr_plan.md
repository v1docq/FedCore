## Доказательства и ограничения

SHA и ancestry относятся к зафиксированному снимку, а не к будущему состоянию GitHub. Количество конфликтов получено трёхсторонним сравнением с текущими tips базовых веток без слияния в рабочую копию. Пустые описания/отсутствие CI не подтверждают исправность.

В release-0.3/generate_text исходный config_factory содержит Markdown-ограждение вместо Python; manifold_losses содержит незавершённый elif. Эти дефекты должны исправляться до запуска выделенных приращений. Тесты новой ветки не подтверждают автоматически работоспособность старых tips.

Существующие #2/#3/#15/#16/#22 сохраняются до сопоставления с результатами новых задач. Частичное перекрытие назначения не означает полного дублирования. Публичный API, независимая исходная модель и успешные проверки являются условиями приёмки переноса.
