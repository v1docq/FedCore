# Трасса действующего оптимизатора FedCore

`FedcoreEvoOptimizer` остаётся действующим оптимизатором графов FedCore. Для записи его работы задайте `AutoMLConfigTemplate.search_trace_path` перед вызовом `FedCore.fit`. Значение по умолчанию — `None`; запись отключена.

Файл JSON содержит конфигурацию критериев и операторов, вероятности мутации и скрещивания, тип агента мутаций, ограничения, обращения к оценщику, популяции, архив и завершение поиска. Для каждого индивида сохраняются идентификатор, описание графа, пригодность, значения критериев и фактический `parent_operator` с идентификаторами родителей. Невычисленные и нечисловые значения пригодности представлены как `null` и не выдаются за измерения.

Трасса не меняет отбор. Использование hypervolume в отборе этого оптимизатора не заявляется. Наличие настроенного оператора скрещивания и его вероятности следует отличать от зарегистрированного события скрещивания: малый запуск может остановиться до такого события. Режим исключительно мутаций по этой трассе автоматически не предполагается.

Время обращения к оценщику включает проверку кэша и всю обработку группы кандидатов, включая неудачные попытки. Это время нельзя делить на размер группы и выдавать за стоимость отдельного кандидата. Для поэтапной оценки затрат отдельного кандидата используется общий запускатель экспериментов PETRA.

Удалён второй вызов `_initial_population` в начале `optimise`: он повторно создавал и оценивал исходную популяцию. Проверка через публичный `FedCore.fit` подтверждает единственную инициализацию и сохранение итогового выбора. Алгоритм поиска, критерии и значения параметров по умолчанию сохранены.

Конечное пространство кандидатов нового экспериментального сравнения использует отдельный профиль GOLEM. Его результаты не следует приписывать поиску по графам `FedcoreEvoOptimizer` без отдельного сравнения.
