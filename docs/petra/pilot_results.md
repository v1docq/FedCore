## Сравнение поиска

18 запусков: две задачи × три начальных состояния (41, 42, 43) × random/evolution/TPE. Лимит — 6 оценок, включая общий обученный исходный вариант; не более 60 секунд с явным учётом возможного превышения последней операцией. Порядок методов меняется по начальному состоянию. Время построения данных учтено. Все 18 поисков завершились успешно.

Эволюционный метод использует настоящий GOLEM EvoGraphOptimizer с SPEA2 в конечной области конфигураций. Это отдельная область поиска; сравнение не доказывает преимущество исходного графового FedcoreEvoOptimizer.

## Область применимости

CV: малый CNN на Digits, один запуск на RTX 4080; это не ResNet на CIFAR10/ImageNette. Табличная модель: BigMLP на Breast Cancer. Временные ряды: имеющиеся файлы AppliancesEnergy; лицензия производного архива отдельно требует проверки. Языковая модель: малый причинный byte-GRU на 32 документах исходного кода FedCore с BSD-3-Clause; это не результат GPT или тест естественного языка.

Отдельный обученный пилот сравнивает ранги 8/15, обычное и взвешенное SVD, регуляризацию, порядок операций, раннюю/позднюю проверку, LoRA, дистилляцию и QAT. Их исходные измерения находятся в final-ablations. Начальное состояние этого пилота — 41. Методологические ограничения описаны в research.md.

JSON содержит параметры, хеши исходного кода, версий, данных и артефактов, исходные времена вызовов и отказы. Модели, тензоры данных и прогнозы остаются в локальном рабочем каталоге и не включены в GitHub; абсолютные пути в паспортах относятся к машине запуска. Копии JSON и таблиц позволяют проверить опубликованные числа; полный повтор требует указанных данных и нового обучения.

## Повтор

Из корня репозитория, после установки .[test,experiments]:

```powershell
python -m fedcore.experiments.pilot --group search --baseline-epochs 15 --output-dir work/search
python -m fedcore.experiments.pilot --group ablations --baseline-epochs 20 --output-dir work/ablations
python -m examples.petra.run --scenario tabular --epochs 20 --finetune-epochs 2 --methods baseline train svd structural_pruning ptq qat --minimum-baseline-quality .9 --output-dir work/tabular
python -m examples.petra.run --scenario cv --device cuda --epochs 15 --finetune-epochs 2 --methods baseline train svd structural_pruning --minimum-baseline-quality .85 --output-dir work/cv
python -m examples.petra.run --scenario ts_regression --epochs 15 --finetune-epochs 2 --output-dir work/ts
```

Для языкового пилота передайте JSON лицензированных независимых документов через --data; схема приведена в examples.md. Длительные подтверждающие эксперименты не запускались. Исторический CoLES отложен: пользователь подтвердил отсутствие доступа к данным и моделям.
