# Примеры и сценарии PETRA

Общая программа запуска обучает исходную модель, создаёт независимые копии её весов и сохраняет фактические измерения. Название старого файла не определяет архитектуру: действительные данные, модель, устройство, бюджет и статус указаны в `manifest.json`. Малый воспроизводимый запуск проверяет путь исполнения; полные таблицы статьи требуют отдельных повторов по заранее закреплённому протоколу.

Реестр `examples/petra/inventory.json` содержит все 75 файлов исходной проверки. Статусы: `supported_example` — поддерживаемая программа запуска; `educational_demonstration` — учебное пояснение; `historical_artifact` — исторический материал; `experimental_prototype` — неподтверждённый прототип. Для удалённых точных дубликатов указан `consolidated_into`. Старые веса, журналы и графики не служат новым доказательством. Для сохранившихся весов приведены контрольные суммы; происхождение обучения неизвестно, загрузка этих весов в новые исходные модели запрещена этим сценарием.

```text
python -m examples.petra.run --scenario tabular --seed 42 --epochs 20 --finetune-epochs 3 --lr 0.001 --methods baseline train svd --minimum-baseline-quality 0.85 --output-dir work/petra_results
python -m examples.petra.view_results work/petra_results
```

`--epochs`, `--lr`, `--batch-size`, `--device` и `--output-dir` управляют исполнением. Нулевое обучение исходной модели отклоняется. `--minimum-baseline-quality` заранее закрепляет нижнюю границу accuracy либо верхнюю границу ошибки; модель, не прошедшая эту проверку на validation, не допускается к сравнению. `--rank-ratio` задаёт сохраняемую долю ранга через стратегию `quantile`: число компонент равно округлённому вверх произведению доли на исходный ранг. Это не порог сохранённой энергии сингулярных значений.

Части train, validation, calibration и test имеют независимые идентификаторы. Параметры заполнения пропусков и масштабирования обучаются только по train; паспорт содержит `preprocessing_fit_ids`, медианы, средние и масштабы. Validation используется для выбора решений. PTQ получает calibration. Test читается после фиксации решений; ошибки и отклонённые варианты сохраняются вместе с успешными попытками. CPU PTQ/QAT и CUDA-обучение требуют отдельных аппаратных протоколов. Плотное маскирование весов методом `pruning` не доказывает структурного сокращения размеров тензоров или ускорения.

Для MSE единицы ошибки возводятся в квадрат; RMSE и MAE сохраняют единицы цели. Нормировку многокритериальной оценки следует фиксировать до запуска: доступны `--quality-scale`, `--cost-scale`, `--hypervolume-reference`. По умолчанию масштаб MSE для регрессии и прогнозирования равен дисперсии цели только по train, а для остальных задач — 1. Масштаб стоимости равен 1 MiB; опорная точка hypervolume — `(2, 2)`. Настройки не подбираются по validation/test после получения результата; вариант вне опорной точки может иметь нулевой вклад в hypervolume. `structural_pruning` — отдельный путь действительного удаления каналов, с проверкой зависимостей и сохранением формы выхода.

| Сценарий | Данные и модель | Граница доказательства |
|---|---|---|
| `cv` по умолчанию | `sklearn.load_digits`, реальные изображения 8×8, `DigitsCNN` | Малый отдельный опыт, не CIFAR-10 и не ImageNette |
| `cv --cv-dataset cifar10` | Локальный официальный CIFAR-10, ResNet18/ResNet50 | Новая модель обучается с нуля, включая изменённые `conv1` и `fc`; полные результаты не заявлены заранее |
| `cv --cv-dataset imagenette` | Локальные `train`/`val`, ResNet18/ResNet50, явная версия и разрешение | `--max-samples` явно отмечает ограниченную пилотную выборку; нужен полный опыт |
| `tabular` | `sklearn.load_breast_cancer`, `BigMLP` | Новый контроль с предобработкой по train; не восстановление OpenML pol |
| `ts_regression` | Локальный AppliancesEnergy `.ts`, `ScaledRegressor(SeriesCNN)` | Регрессия суммарного энергопотребления, без обещания InceptionTime или прогнозирования будущего |
| `ts_classification` | Локальный CinCECGTorso `.tsv`, `SeriesCNN` | Архивные train/test; принадлежность пациентам не восстанавливается из TSV |
| `forecasting` | Исходный UCI `energydata_complete.csv`, `SeriesCNN`, явный горизонт | Настоящий прогноз будущего по прошлым значениям; требуется исходный CSV |
| `open_sequence` | Открытые изображения цифр как 8 последовательных строк, `SeriesCNN` | Самостоятельная классификация последовательностей, не финансовые данные и не CoLES |
| `financial` | Разрешённые локальные последовательности клиентов и паспорт доступа | Строгий путь к доступным данным; Alpha/Age и CoLES не восстановлены |
| `lm` | Лицензированные независимые документы, UTF-8, causal GRU | Корректный малый опыт NLL/PPL; не сравнение больших языковых моделей |

Для CIFAR-10 и ImageNette:

```text
python -m examples.petra.run --scenario cv --cv-dataset cifar10 --data /path/to/cifar --architecture resnet18 --epochs 100 --methods baseline train svd --output-dir work/cifar10
python -m examples.petra.run --scenario cv --cv-dataset imagenette --data /path/to/imagenette2-160 --dataset-revision imagenette2-160 --architecture resnet50 --resolution 128 --max-samples 2000 --epochs 20 --methods baseline train svd --output-dir work/imagenette_pilot
```

Официальные источники: [CIFAR-10](https://www.cs.toronto.edu/~kriz/cifar.html) и [ImageNette](https://github.com/fastai/imagenette). Для ImageNette проверяется совпадение десяти классов в `train` и `val`; официальный `val` сохраняется как независимый test, а validation/calibration выделяются из `train`. Примеры не скачивают данные. Условия повторного использования изображений следует проверять по исходному набору; их нельзя выводить из лицензии программного кода репозитория.

Для AppliancesEnergy архивные TRAIN/TEST сохраняются. Строгий разбор `.ts` учитывает временные метки внутри каждой из 24 компонент и проверяет отсутствие пересечения исходных интервалов между частями данных. Порядок TRAIN/TEST не объявляется хронологическим. Масштабирование цели сохраняется в модели, поэтому предсказания и ошибки относятся к исходным единицам: заголовок производного архива указывает kWh. [Исходный UCI набор](https://archive.ics.uci.edu/dataset/374/appliances+energy+prediction) задаёт `Appliances` в Wh, то есть единицы производного `.ts` и исходного CSV различаются. Происхождение преобразования и лицензия производного архива ещё требуют подтверждения перед публикацией новых научных результатов.

В `forecasting` CSV должен содержать возрастающие уникальные временные метки с шагом 10 минут. Контекст и целевой горизонт целиком находятся внутри одной части данных. Окна, которые пересекли бы границу, исключаются; масштабирование не видит будущих строк. Например:

```text
python -m examples.petra.run --scenario forecasting --data /path/to/energydata_complete.csv --context 24 --horizon 6 --epochs 20 --methods baseline train svd --output-dir work/forecasting
```

Для отдельного открытого последовательностного опыта:

```text
python -m examples.petra.sequence --epochs 20 --finetune-epochs 3 --seed 42 --output-dir work/open_sequence
```

Он обучает общий `SeriesCNN`, сравнивает исходные веса, обычное дообучение и SVD, замораживает извлечённые признаки и обучает одинаково настроенный LightGBM. Дополнительный контроль использует среднее, стандартное отклонение, минимум, максимум и последнее значение каждого канала. Стоимость кодировщика и всего пути «подготовленный тензор → признаки → LightGBM» измеряется отдельно. Изображение служит единицей независимости; авторы рукописных цифр не восстанавливаются. [Источник цифр](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits) и [источник Breast Cancer Wisconsin](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic) указывают CC BY 4.0. Эти ссылки проверены 05.10.2026. Открытый опыт не подтверждает исторические финансовые выводы.

Владелец сообщил об отсутствии доступа к Alpha/Age и исходным весам. Восстановление исторического CoLES остаётся отдельной незавершённой задачей. Для новых разрешённых данных `financial` принимает NPZ с `x[N,T,F]`, целочисленным `y[N]`, `client_ids[N]` и JSON с `source`, `revision`, `license`, `access_authorized: true`, `dataset_sha256`, `task: "classification"`, `target_definition`. Полные клиенты назначаются частям данных до предобработки. Наличие файла без разрешения доступа и совпадающей контрольной суммы не допускает запуск. Предоставленный путь обучает `SeriesCNN`, не выдавая его за CoLES.

Языковой сценарий принимает JSON с `source`, `revision`, `license` и списком `documents`, где каждый элемент содержит уникальные `id` и `text`. Документы распределяются до токенизации; повторы содержания отклоняются. Фиксированный токенизатор `utf8-byte-v1` не обучается на test. Модель предсказывает следующий токен: `logits[:, :-1]` сравниваются с `labels[:, 1:]`; дополнение коротких последовательностей имеет метку `-100`. Средняя отрицательная логарифмическая вероятность (NLL) усредняется по действительным токенам; перплексия (PPL) равна `exp(NLL)`. Нефинитные значения отклоняются. Документы разбиваются на непересекающиеся фрагменты; состояние модели сбрасывается между фрагментами, а переходы через их границы не оцениваются. Независимая проверка на малых логитах обнаруживает неправильный сдвиг. Обработка входного запроса (prefill), пошаговая генерация (decode) и время до первого токена (TTFT) требуют отдельного реально работающего пути и одинаковых запросов; эти измерения в данном сценарии не выполняются.

```text
python -m examples.petra.run --scenario lm --data /path/to/licensed_documents.json --epochs 20 --methods baseline train svd --output-dir work/lm
```

Блокноты содержат только пояснения и чтение проверяемых записей. Если измеренный запуск отсутствует, читатель сообщает об отсутствии файла, а не подставляет старые числа. Учебный `examples/app.py` хранит файлы; его `/export` возвращает `501` и `unsupported`. Реальное преобразование и проверку исполняемого артефакта выполняет публичный FedCore/export-контур.

Опубликованный ранее токен удалён из исходника и всех сохранённых выводов. Владелец 05.10.2026 подтвердил, что токен отозван или недействителен; независимая сетевая проверка не выполнялась. Значение не сохраняется. `python scripts/check_example_secrets.py examples` проверяет исходники, выводы блокнотов и распакованные члены ZIP, печатая только имя найденного файла. Переписывание Git-истории в эту работу не входит.

`python -m examples.petra.package` пересобирает ZIP из действительных файлов, сохраняя контрольные суммы в `PACKAGE_MANIFEST.json`. Архив содержит программы и инструкции, не расходящиеся копии сервисов и не заранее объявленные результаты. Локальные проверки: `python -m pytest tests/petra/test_examples_scenarios.py -q` и проверка секретов. Для научных выводов отдельно требуются исходные наборы/лицензии, приемлемое качество обученного контроля, полные аппаратные измерения и все заранее согласованные повторы.
