# Исполнение и перенос разреженных профилей

`BasePruner.compress_profile(model, method, spec, calibration=..., target_paths=...)` вызывает общий обработчик `transform_sparse`. Результат содержит независимую модель, неизменяемый план и конечные JSON-метаданные. Планы хранят параметры и пути модулей; модели, тензоры, загрузчики и оптимизаторы в них не попадают. Исходная модель не изменяется. Для HASSLE-free калибровка каждого следующего слоя использует уже преобразованные предшествующие слои в объявленном порядке.

`ExperimentRunner.apply_candidate` принимает явные `spec` и `target_paths` для HASSLE-free, LoSparse, SoLA, FlexiGPT, PruneNet и MoE-I². LoSparse обучается через существующий `train_model` и `LoSparseTrainingCallback`; окончательная упаковка разрешена только после завершения объявленного расписания. Промежуточный плотный остаток и EMA в конечный переносимый оператор не входят.

TEDEPR возвращает `insufficient_specification` до обхода модели, копирования, чтения данных и изменения случайного состояния. Произвольное разложение с маской не считается реализацией TEDEPR.

## Матрица допуска

| Представление | Профиль | Внутренняя контрольная точка | TorchScript | ONNX | Внешний контракт |
|---|---|---|---|---|---|
| `PackedNMLinear` | CPU float32/float64, статические ширины | Да, без фабрики | Проверяется на конечном артефакте | Не допущен этой серией | v4: только `hassle_free` |
| `IndexedResidualLinear` | CPU float32/float64, статические ширины | Да, после завершения обучения | Проверяется на конечном артефакте | Не допущен этой серией | Не допущен |
| `SparseMLP`, `PartitionedMLP` | Явный FFN, CPU float32/float64 | Да, с картами каналов | Проверяется на конечном артефакте | Не допущен этой серией | Не допущен |
| `FlexiGPTTransformer` | Ограниченный причинный граф, CPU float32/float64 | Да, с общими ссылками | Проверяется на конкретном графе | Не допущен этой серией | Не допущен: общие основы требуют отдельной схемы |
| `ReferenceMoE` | Явный маршрутизатор top-k, CPU float32/float64 | Да, рекурсивно с экспертами | Только проверенная конкретная трасса | Не допущен этой серией | Не допущен: динамическая маршрутизация требует отдельной схемы |
| `LoSparseTrainingLinear` | Обучение с плотным остатком и EMA | Не является конечным переносимым типом | Не допущен | Не допущен | Не допущен |
| TEDEPR | Недостаточно спецификации | Нет | Нет | Нет | Нет |

Внутренний формат разрешает только явный список конструкторов, конечные значения метаданных и ограниченную память до создания тензоров. Перед загрузкой проверяются формы, типы данных, координаты поддержки и общие ссылки. Описания факторизованных MoE-экспертов сохраняют их фактические дочерние операторы. Плотная копия исходного веса при восстановлении не подменяет конечное представление.

Внешние версии v1–v3 сохраняют прежние ограничения. v4 добавляет один профиль: исходный граф `Linear`/`Sequential` из существующего списка, `HASSLEFreeSpec`, независимая калибровка, CPU и TorchScript. Поле `rank` запроса не используется: ранг задаётся внутри `sparse_profile.spec.structure`. Неизвестные параметры, ONNX, CUDA и неразрешённые методы отклоняются. Запрет общих модулей, параметров и представлений общего хранилища во внешнем формате сохраняется.

## Воспроизводимая малая серия

Из рабочего дерева:

```powershell
python -m examples.sparse_compression.profiles --output work/sparse-demo --seed 17
python -m examples.sparse_compression.external_cpu --output work/sparse-external-demo
```

Для проверки установленного wheel скопируйте `examples/sparse_compression/profiles.py` вне рабочего дерева и запустите его интерпретатором окружения, где установлен wheel:

```powershell
python profiles.py --output sparse-results --seed 17
```

Серия не скачивает модели или данные. Она сравнивает исходный, преобразованный, восстановленный и экспортированный результаты на независимых синтетических входах. Обучающие входы LoSparse отделены от калибровки и оценки. Порог ошибки и правило полезности задаются до преобразований. `measure_artifact` экспортирует, загружает, проверяет выходы и измеряет конечный исполняемый файл; отчёт сохраняет реальные байты параметров и буферов, байты контрольной точки и файла, сырые времена, стоимость подготовки и ограничения памяти.

Нулевая маска и теоретическое число операций не считаются измерением. Например, индексы int64 могут сделать маленький N:M-оператор тяжелее плотного слоя; такой результат должен оставаться отрицательным в отчёте. Наблюдения RSS являются снимками процесса и не измеряют пиковую память модели.

Малая серия проверяет механизм и перенос. Она не подтверждает качество на предобученной модели, таблицы статей, ускорение GPU, динамическую генерацию или сокращение KV-кэша. Полная матрица абляций, восстановление всех архитектур после преобразования и опыт на реальном профиле качества остаются отдельными этапами SP15.

Выполненная серия с `seed=17` содержит 16 вариантов: три HASSLE, три LoSparse, три SoLA, три PruneNet, FlexiGPT и три MoE. Для каждого проверены контрольная точка без фабрики и конечный TorchScript-файл. Отдельный пример `external_cpu.py` прошёл путь `client.compress` → изолированный рабочий процесс → артефакт контракта v4. Эти результаты относятся к малому синтетическому профилю. Численные результаты и реальные размеры записываются в `report.json` и `external-report.json`; временные результаты зависят от машины и повторяются при каждом запуске.
