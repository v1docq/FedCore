# Журнал реализации графа квантования

База: `69458e86d8d42f37c156da67e1a333241d269790`; отдельная ветка `quantization_graph`. Один PR охватывает P0–P7. Проверенный профиль — CPU `Linear`; аппаратное ускорение и качество больших моделей не заявляются.

## P0

Добавлены типы процесса, представления и исполнения, настоящая упаковка 2/4/8 бит, отдельные симметричная сетка и сетка с `2^B` узлами для LPLR. Нулевой диапазон последней имеет явный формат с нулевым масштабом и точным нулевым декодированием. Готовые факторы кодируются без повторной SVD. Переносимые слои сохраняются через разрешённые конструкторы `CheckpointManager`; исполнитель проверяет физические байты и выход загруженной модели. Копирование и применение сохраняют исходную модель.

Проверки: `python -m pytest tests/refactoring/test_quantization_graph_formats.py -q` — 19 успешно. Совместный первоначальный запуск с `test_compression_composition.py` подтвердил 16 прежних проверок G5; новая проверка выявила неверное имя метода сериализации и отсутствие обязательных аргументов существующих границ, исправлено. Обнаружено и исправлено ошибочное использование логической проверки `ValidationFailure`, у которого `__bool__` возвращает `False`.

Выбор хранения: компактный `uint8` плюс масштаб `float64`; распаковка при исполнении, без сохранённой плотной матрицы. Это переносимый численный эталон, не INT4/INT8 GEMM. Время распаковки линейно по числу элементов; плотное декодирование временно расходует память. Предварительный предел памяти — консервативный порог, не измеренный максимум.

## P1 и P2

LPLR и LPLR-SVD сохраняют квантованный первый фактор перед регрессией. Ширина `m` и ранг сравнения `k` различаются. Используется существующая устойчивая регрессия с явным транспонированием коэффициентов; генератор принадлежит исполнителю. Проверены случайная проекция, точная сетка с `2^B` узлами, насыщение, нулевой диапазон, воспроизводимость и загрузка.

CALDERA реализована в ограниченном профиле CPU/scalar. LDLQ использует настоящий перенос ошибки в обратном порядке столбцов для `H=L D Lᵀ`. Взвешенная SVD использует общее подготовленное ядро; внутренние шаги последовательно решают регрессии обоих факторов с квантованием. Число итераций ограничено, сохраняется лучший дискретный кандидат вместе с обеими ветвями и единственным смещением. Поддержка вырожденной метрики и регуляризация различаются явно.

Проверка `python -m pytest tests/refactoring/test_quantization_graph_methods.py -q` — 8 успешно. Независимые эталоны используют псевдообратную для LPLR и скалярный цикл LDLQ с фактором Cholesky; проверены полный и вырожденный второй момент. Первый запуск выявил неверное имя поля диагностики существующей регрессии; исправлено на `design_rank`. Это малые численные проверки, не воспроизведение QuIP#/E8 или качества LLM.

P3–P7 продолжаются в этой ветке; эти поставки не означают завершения PR.
