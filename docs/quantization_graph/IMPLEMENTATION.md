# Журнал реализации графа квантования

База: `69458e86d8d42f37c156da67e1a333241d269790`; отдельная ветка `quantization_graph`. Один PR охватывает P0–P7. Проверенный профиль — CPU `Linear`; аппаратное ускорение и качество больших моделей не заявляются.

## P0

Добавлены типы процесса, представления и исполнения, настоящая упаковка 2/4/8 бит, отдельные симметричная сетка и сетка с `2^B` узлами для LPLR. Нулевой диапазон последней имеет явный формат с нулевым масштабом и точным нулевым декодированием. Готовые факторы кодируются без повторной SVD. Переносимые слои сохраняются через разрешённые конструкторы `CheckpointManager`; исполнитель проверяет физические байты и выход загруженной модели. Копирование и применение сохраняют исходную модель.

Проверки: `python -m pytest tests/refactoring/test_quantization_graph_formats.py -q` — 19 успешно. Совместный первоначальный запуск с `test_compression_composition.py` подтвердил 16 прежних проверок G5; новая проверка выявила неверное имя метода сериализации и отсутствие обязательных аргументов существующих границ, исправлено. Обнаружено и исправлено ошибочное использование логической проверки `ValidationFailure`, у которого `__bool__` возвращает `False`.

Выбор хранения: компактный `uint8` плюс масштаб `float64`; распаковка при исполнении, без сохранённой плотной матрицы. Это переносимый численный эталон, не INT4/INT8 GEMM. Время распаковки линейно по числу элементов; плотное декодирование временно расходует память. Предварительный предел памяти — консервативный порог, не измеренный максимум.

## P1 и P2

LPLR и LPLR-SVD сохраняют квантованный первый фактор перед регрессией. Ширина `m` и ранг сравнения `k` различаются. Используется существующая устойчивая регрессия с явным транспонированием коэффициентов; генератор принадлежит исполнителю. Проверены случайная проекция, точная сетка с `2^B` узлами, насыщение, нулевой диапазон, воспроизводимость и загрузка.

CALDERA реализована в ограниченном профиле CPU/scalar. LDLQ использует настоящий перенос ошибки в обратном порядке столбцов для `H=L D Lᵀ`. Взвешенная SVD использует общее подготовленное ядро; внутренние шаги последовательно решают регрессии обоих факторов с квантованием. Число итераций ограничено, сохраняется лучший дискретный кандидат вместе с обеими ветвями и единственным смещением. Поддержка вырожденной метрики и регуляризация различаются явно.

Проверка `python -m pytest tests/refactoring/test_quantization_graph_methods.py -q` — 8 успешно. Независимые эталоны используют псевдообратную для LPLR и скалярный цикл LDLQ с фактором Cholesky; проверены полный и вырожденный второй момент. Первый запуск выявил неверное имя поля диагностики существующей регрессии; исправлено на `design_rank`. Это малые численные проверки, не воспроизведение QuIP#/E8 или качества LLM.

## P3

Tender поддерживает `Linear` с общей поканальной калибровкой, фиксированными центрами, степенными масштабами активаций, масштабами весов по выходам и целочисленной рекурсией. Индексы обеих сторон сохраняются и проверяются. Пропущенные уровни увеличивают сдвиг. Центр компенсируется через деквантованный вес; формат и отказ при переполнении заданы явно. Каждый промежуточный продукт, сумма и сдвиг проверяются Python-целыми до преобразования в `int64`.

Проверка `python -m pytest tests/refactoring/test_quantization_graph_tender.py tests/refactoring/test_quantization_graph_methods.py -q` — 14 успешно. Независимые сумма групп в общей целочисленной шкале и деквантованная сумма совпадают с исполнителем; проверены нулевые диапазоны, центр, повреждение индексов/групп и переполнение. Метаданные общие для входных каналов, поэтому новые длины используют ту же калибровку. `row-chunk`, `per-head`, `Tender(all)` и аппаратное ускорение этим профилем не покрыты.

После независимого чтения основным агентом исправлены относительный порог LDL для малых масштабов H и пропуск оценки промежуточной квантованной SVD-инициализации. Несовместимые форматы LPLR/CALDERA/Tender отклоняются при проверке плана до вычислений.

## P4

Каталог использует существующие `CandidateTable`, точный распределитель и независимый перебор. Для dense/PTQ/Tender введён обратно совместимый вариант `structure="unranked"` с пустым `ranks`, без фиктивного ранга. Общие псевдонимы входят в одну область. Все варианты при наличии калибровки оцениваются по одной ошибке выхода на фактических входах оператора; без калибровки используется ошибка веса. Полная модель повторно строится, загружается и оценивается отдельно от локального суррогата. Сохраняются реальные байты всех весов, метаданных и неизменённых параметров.

Проверка `python -m pytest tests/refactoring/test_quantization_graph_catalogue.py -q` — 2 успешно: распределитель совпадает с независимым перебором, смешанная модель исполняется после загрузки, общий слой учитывается один раз, смена калибровки отклоняет каталог. Команда с несуществующим `test_allocation.py` не запустила проверки; правильный прежний файл — `test_svd_allocation.py`.

## P5

Адаптер передаёт текущему `BaseQuantizer` одну региональную `QConfigMapping` с вещественными границами. Выполняются `prepare`, реальные ограниченные обновления и `convert`; журнал хранит число шагов и изменения параметров. Обратный переход из сконвертированного графа к QAT отклоняется. Восстановление факторов явно декодирует их в обучаемый `FactorizedLinear`, использует существующие стадии LoRA с новым оптимизатором на каждой стадии, затем кодирует готовые факторы без повторной SVD.

CPU backend получает проверяемый адаптер хранения: коды, параметры квантования и смещение зарегистрированы как обычные буферы. Непрозрачный постоянный packed-объект не сохраняется; `linear_prepack` выполняется как явная временная операция инференса. Restricted FX-процесс имеет разрешённые операции, сохраняется через `CheckpointManager` и проверяется на точное совпадение выхода с исходным результатом `convert`. Хранение буферов и размер файла приводятся отдельно; временная память prepack и полная память Python-объекта не выдаются за измеренные.

Проверка `python -m pytest tests/refactoring/test_quantization_graph_training.py -q` — 4 успешно: static/QAT с региональными границами, реальные изменения и независимый вещественный контроль, точная загрузка backend, отказ при исчерпании бюджета с учётом попытки, восстановление обоих факторов и неизменность источника. Предупреждения касаются существующих `pkg_resources` и PyTorch `reduce_range`.

P6–P7 продолжаются в этой ветке; эти поставки не означают завершения PR.
