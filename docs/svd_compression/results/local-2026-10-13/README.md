# Результаты локального сравнения SVD

Серия от 13.10.2026: шесть обученных исходных моделей, 90 вариантов сжатия и 96 отдельных процессов измерения времени. [Полный анализ](../../LOCAL_COMPARISON.md) объясняет методику, результаты и ограничения.

- `analysis.json`, `candidates.csv`, `paired.csv`, `layers.csv` — анализ, рассчитанный из исходных результатов по seed, без выбора удачных вариантов.
- `summary.json`, `protocol.json`, `runs/` — настройки, разбиения, хеши моделей, фактические формы, качество и ошибки слоёв.
- `timing/` — 96 сессий с профилем, процессом и 200 сырыми временами в каждой; `raw-timing.csv` содержит те же 19 200 наблюдений для повторного расчёта.
- `final-audit.json`, `numerical-audit.json`, `independent-review.json` — сверки полноты, размеров, качества, экспорта, ресурсов и исходников.
- `validation.json` — результаты общего прогона и проверки сборки; `resource-observations.json` — наблюдения ресурсов численных процессов.
- `publication-manifest.json` — SHA256 исходных и опубликованных файлов и проверка неизменности всех значений, кроме путей.

В опубликованных JSON абсолютные пути рабочей машины заменены относительными префиксами `run-v1`, `run-v2`, `study`, `repository`. Числа, настройки и вложенные хеши исходных протоколов, моделей и артефактов сохранены. Вложенные хеши относятся к первоначальным локальным файлам; для опубликованных копий используется `published_sha256` паспорта публикации. Это переносимая копия доказательств, а не изменение исторического протокола.

Бинарные веса, контрольные точки и TorchScript сохранены локально в каталоге серии `work/svd-local-comparison-2026-10-13/run-v2` рядом с клоном репозитория. Публикация позволяет проверить арифметику результатов и происхождение, но повторное исполнение именно этих артефактов требует локальных бинарных файлов. Новый полный запуск выполняется командами из отчёта.

Три seed описывают малую серию обучения. 200 замеров внутри процесса не являются 200 независимыми обучениями. Время приведено как наблюдение сессии: фоновая нагрузка CPU 1,9–40,1% не позволяет приписать различия алгоритмам.
