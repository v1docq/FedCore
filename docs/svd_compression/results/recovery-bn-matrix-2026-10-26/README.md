# Матрица восстановления и дополнительной BN, 26.10.2026

Одна утверждённая попытка завершилась: 5 фиксированных графов × 3 состояния обучения × 2 режима дополнительной BN = 30 оценок. Выполнены 10 траекторий по 200 обновлений и 150 000 новых строк на одной поисковой выборке. Шесть плотных условий точно воспроизвели прошлые массивы, включая потери. Официальная тестовая выборка, новый поиск и аппаратные измерения в этом пакете не запускались.

Внешний расход — 178,7692715227604 с, прежний — 3648,862081296742 с, общий — 3827,6313528195024 с / 63,79 из 240 минут. Рабочая часть — 176,29581467807293 с; она не подменяет полный внешний расход. Повторов не было.

`raw/` — побайтный экспорт одной завершённой попытки. 41 бинарный файл `.pt`, включая снимки и копии реестра, остаётся на A100. `recovery-file-inventory.json` хранит SHA-256, размеры и объёмы тензорных ZIP-хранилищ из удалённого экспорта; локальные байты весов не пересчитывались. Архив передачи не дублируется в Git; его SHA находится в `validation/recovery-export-receipt.json`. Файл унаследованных исходных предсказаний M0 в `inherited/` — отдельный вход, не ещё одна новая оценка.

`inputs/` — побайтные копии необходимых предыдущих отчётов, списка зависимостей и шести плотных NPZ для независимого воспроизведения. `validation/` содержит локальные CPU-журналы, два примера проверки ограничителя и сохранность рабочих копий. Linux installed checks, предварительный допуск и удалённая сохранность включены в `raw/`. Первичная серия содержит четыре сбоя тестовой фикстуры; после двухстрочного исправления целевые и окончательные проверки прошли. Вычислительный валидатор не менялся ради допуска.

Независимый анализ требует Python 3.10 и NumPy 1.26.4, без PyTorch/CUDA и исполнения моделей. Из этого каталога укажите новые выходные каталоги:

```powershell
python tools/analyze_recovery_bn.py raw C:/path/to/new-analysis --completion-report inputs/completion/report.json --diagnostic-root inputs/diagnostic
python tools/build_recovery_bn_report.py C:/path/to/new-analysis C:/path/to/new-report
```

Ожидается `completed`, 746 согласованных проверок, 2000 обновлений, 150 000 новых строк. MD/HTML размещаются рядом с `results`, чтобы относительные ссылки работали. HTML самодостаточен, внешние библиотеки не нужны. Для завершённого пакета анализ/отчёты должны воспроизвестись побайтно. Анализатор также сохраняет свидетельства частичного выполнения при наличии итогового `report.json`; это не обещает восстановление отчёта после принудительного завершения до его записи.

Обучаемые параметры совпадают в 15 BN-парах; обе ветви независимо загружены из одного снимка. Оба шага обучения начинаются с общего состояния своего семейства без дополнительной калибровки. Последовательность «дополнительная BN, затем SGD» не проверялась. Используются прежние выбранные генотипы; SVD и R — один граф. Общая issue #99 остаётся открытой.

Манифест фиксирует байты всех опубликованных материалов и обоих отчётов; собственный хеш в него не включается. Старые серии и их манифесты не переписываются.
