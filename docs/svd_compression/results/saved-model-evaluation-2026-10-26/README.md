# Оценка пяти сохранённых моделей, 26.10.2026

Одна разрешённая попытка завершилась: пять исходных моделей и пять независимо загруженных TorchScript × 5000 поисковых изображений, затем пять тех же TorchScript × 10 000 изображений ранее использованного официального теста. Всего 100 000 новых строк, 0 обновлений SGD. Все семь полных A/A прошли; четыре A/B окончательно допущены после заключительного контроля и успешного завершения. Сохранены все 440 пар без удаления выбросов.

Это заранее закреплённые состояния SGD 0.001 без дополнительной BN из прежней матрицы. Контроль M0 также прошёл 200 обновлений. Тестовая оценка описательная: тест уже использовался, независимой окончательной оценки здесь нет. Новый поиск не проводился. Issue #99 остаётся открытой.

Полный внешний расход 153,86317451670766 с; предыдущий 3827,6313528195024 с; общий 3981,49452733621 с / 66,36 из 240 минут. Рабочая часть 151,67364954203367 с не подменяет внешний расход. Повтора не было.

`raw/` — побайтный экспорт одной завершённой попытки: NPZ, 11 журналов с парами, фиксация пяти состояний, среда, происхождение, контроль целостности и управляющие журналы. Десять `.pt` (пять исходных и пять TorchScript) остаются на A100. `evaluation-file-inventory.json` хранит их удалённо проверенные SHA-256, размеры файлов и тензорных ZIP-хранилищ. Локальные байты весов не скачивались и не пересчитывались. Архив передачи в Git не дублируется; его SHA и размер находятся в `validation/saved-evaluation-export-receipt.json`. Последний полный префикс предсказаний сохранялся после каждого пакета; журнал содержит последовательность префиксов, отдельный NPZ для каждого префикса не обещается.

`inputs/` — побайтные копии родительского отчёта, списка зависимостей и одного исторического NPZ для независимой проверки идентификаторов/меток официального теста. Чтение старого NPZ не является новым исполнением модели на тесте. Пять предыдущих поисковых NPZ уже включены в `raw/inherited/`. `validation/` содержит журналы CPU-проверок, квитанцию экспорта, сохранность рабочих копий и состояние CI кода. `analysis/` содержит 454 независимые проверки и численные итоги.

Для пересчёта нужны Python 3.10 и NumPy 1.26.4; модели, PyTorch и CUDA не используются. Из этого каталога укажите новые выходные каталоги:

```powershell
python tools/analyze_saved_evaluation.py raw C:/path/to/new-analysis --parent-report inputs/recovery/report.json --parent-freeze inputs/recovery/environment_freeze.txt --historical-test-npz inputs/historical/official_test.npz
python tools/build_saved_evaluation_report.py C:/path/to/new-analysis raw C:/path/to/new-report
```

Ожидается `completed`, 454 согласованные проверки, 100 000 строк, 440 пар, четыре допущенных A/B и 0 обновлений SGD. Анализ и оба отчёта должны воспроизвестись побайтно. MD/HTML размещаются рядом с `results/`, чтобы относительные ссылки работали; интерактивные таблицы и SVG встроены в HTML и не требуют сети.

Анализатор умеет раскрывать ранний частичный результат в пределах имеющихся управляющих файлов и не создаёт научных таблиц при отсутствии научного экспорта. Генератор нынешнего отчёта принимает только проверенный завершённый пакет. Это не обещает восстановление любых повреждённых или не успевших сохраниться файлов. Полное повторное исполнение требует весов на A100, данных и нового вычислительного разрешения.

Все старые серии и их манифесты сохранены. Новый манифест фиксирует все материалы этого каталога и два итоговых отчёта; собственный хеш в него не включается.
