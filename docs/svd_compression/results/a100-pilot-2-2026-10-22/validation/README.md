# Проверка исправления записи поиска

Это локальные CPU-проверки исправленного кода, выполненные после остановки GPU-пилота. Они не меняют исходные данные в `../raw/` и не являются повторным вычислением качества моделей.

- `before-fix`: первый вызов остановлен ограничением файловой песочницы на атомарной записи.
- `reproduction`: разрешённый CPU-вызов воспроизвёл две ошибки TypeError исходного кода на обеих границах JSON.
- `after-fix`: первая проверка правки обнаружила неполную имитацию данных в новом тесте; она исправлена.
- `regression`: окончательная серия — 199 passed, 2 skipped за 56,78 секунды, одно предупреждение устаревшего pkg_resources в зависимости.

Новые проверки используют реальные типизированные CVGenotype, проверяют явный формат записи, сохранение исходных объектов и идентификаторов, обе границы записи, отказ для некорректных победителей и пустой архив. Обучение, CUDA и загрузка данных не выполнялись. Исходный научный пакет A100 не изменён и по-прежнему соответствует коммиту 3bc0825a9ef1bcd0ac8eb0181b6d5314b57ebb8d.
