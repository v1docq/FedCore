# Численные данные второго локального пакета

Данные относятся к [PR #140](https://github.com/v1docq/FedCore/pull/140). Постановка, результаты и ограничения приведены в [отчёте](../../SECOND_LOCAL_PACKAGE.md); графики — в [HTML-инфографике](../../second-local-package-infographic.html).

`protocol.json` фиксирует расписание, исходные модели и данные, режим исполнения и лимиты. `timing.json` содержит все исходы измерений времени, включая индивидуальные вызовы, допуск до запуска и наблюдения после выхода процесса. `profiling.json` содержит исходы отдельного профилирования и строки операторов. В каталогах `timing`, `profiling` и `pilot` сохранены наблюдения ресурсов собственных процессов.

`analysis/analysis.json` и три CSV содержат вычисленные отношения и сводки. Программа анализа использует только стандартную библиотеку Python. Из корня репозитория можно повторить расчёт в новом каталоге:

```powershell
python scripts/analyze_svd_second_package.py --input docs/svd_compression/results/second-local-2026-10-14 --output work/second-local-recomputed
```

Для численного пересчёта обученные модели и CUDA не нужны. Для повторения самих измерений потребуются локальные архивы моделей и данных, указанные в протоколе, и сопоставимое окружение. Сохранённые значения точности относятся к первой серии; второй пакет не обучает модели заново.

## Происхождение файлов

`publication-manifest.json` связывает хеши неизменных локальных исходников с хешами опубликованных файлов. При публикации заменены только локальные корни путей и формат сериализации: JSON и CSV сохранены в UTF-8 с LF. Числа, статусы и остальные метаданные сохранены. Идентичность протокола относится к исходному локальному протоколу до замены путей; её нельзя получить повторным хешированием переносимой копии. По той же причине хеши входных JSON при повторном анализе опубликованных данных будут отличаться от записанных для локальных исходников. Численные сводки должны совпадать.

Имена локальных корней: `local-svd-second-package` — завершённая V2; `aborted-svd-second-package-v1` — остановленная V1; `local-svd-package` — первый пакет; `historical-run-v2` — сравнение от 13 октября; `FedCore` — рабочая копия репозитория. Это обозначения происхождения, а не доступные внутри Git файлы моделей.

`ledger-scientific.json` сохраняет учёт на момент окончания измерений. `ledger.json` дополнительно учитывает явно объявленный резерв окончательных проверок. Обязательные наблюдения и паузы, дополнительное ожидание из-за нагрузки и вычислительное время учитываются раздельно. Консервативные резервы не являются измеренным временем обучения.

## Остановленная попытка V1

Каталог `aborted-v1` сохраняет отдельный протокол, учёт, все 43 завершённых исхода, наблюдения ресурсов и четыре журнала ошибок. В `stop-audit.json` также зафиксирована попытка, остановленная до запуска процесса. Все результаты V1 исключены из оценок V2; её полный вычислительный расход перенесён в общий лимит.

`source-frozen.zip` содержит точные байты 261 Python-файла остановленной V1; `source-manifest.json` — их хеши. Этот архив нужен для проверки происхождения старых исходов. Действующие исходники V2 находятся в обычном дереве репозитория.

Обученные двоичные архивы и полные трассы профилировщика остаются локально. Публикация содержит их идентификаторы и строки операторов, но сама по себе не позволяет просмотреть отсутствующие трассы ядер. Профилированные времена не входят в отношения обычной задержки.
