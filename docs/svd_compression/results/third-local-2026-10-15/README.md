# Данные третьего локального пакета SVD

Серия завершена 15.10.2026. [Полный отчёт](../../THIRD_LOCAL_PACKAGE.md) и [интерактивная инфографика](../../third-local-package-infographic.html) поясняют результаты и ограничения.

В архиве сохранены все шесть процессов измерения времени: четыре предварительных и две основные серии. Всего 600 полных парных единиц, 1200 сторон; исходные векторы содержат 20 800 времён завершённого вызова, 20 800 времён полного пути, 10 400 интервалов CUDA Events и 1200 длительностей блоков по 50 вызовов. Ещё один процесс подготовил пять графов из уже существовавших контрольных точек. Нового обучения не было.

Только **CPU, один поток, пакет 64** прошёл предварительный и итоговый контроль. CPU1 и GPU1 остановились после предварительного контроля. GPU64 сохранил основную серию, но не прошёл итоговый контроль; его отношения остаются диагностическими. Код 0 и `status='succeeded'` обозначают успешное выполнение процесса и не заменяют поле `ranking_eligible`.

## Состав

- `protocol.json`, `prospective.json`, `source-freeze.json`: зафиксированные графы, источники, порядок, допуски и условия выполнения.
- `run.json`: индекс всех проведённых этапов и исходов контроля; `ledger.json`: исходный научный учёт с резервом 300 с на предварительные проверки.
- `attempts/`: исходы, исходные времена каждой стороны в `calls.jsonl`, допуски и журналы собственных ресурсов. Неудачные контроли сохранены полностью.
- `analysis/analysis.json`, `blocks.csv`, `comparisons.csv`: описательные сводки и парные отношения; доверительные интервалы не заявляются.
- `independent-review.json`: независимая арифметическая проверка, происхождение данных, 264 исходных файла и сохранность 6368 файлов предыдущего пакета.
- `frozen-source.zip`: точные 264 научных исходных файла в каноническом LF до запуска серии. Изменения разделителей путей для переноса выполняет отдельная программа, добавленная после измерений.
- `validation.json`, `validation-process/`: итоговые регрессионные проверки после завершения всех измерений.
- `portable-replay/`: проверка переносимого пересчёта и подтверждение сохранности исходников.
- `qa/`: программы публикации и проверки, журналы предварительных тестов. Первые два отказа стандартной временной папки Windows отмечены как ограничения записи; полный первоначальный стек остался в журнале чата. Последующие успешные прогоны имеют полные журналы.
- `scientific-raw-manifest.json`, `publication-manifest.json`: хеши локального научного архива и опубликованных копий. Модели и входные тензоры остаются локально; их хеши сохранены.
- `final-ledger.json`: отдельный итоговый учёт с проверками, сохраняющий исходный `ledger.json` неизменным.

Публикация сохраняет исходные байты JSON/CSV/журналов. Абсолютные локальные пути остаются метаданными происхождения; численный пересчёт использует только относительный индекс результатов. Хеши исходного протокола поэтому остаются проверяемыми.

## Пересчёт без PyTorch

Из корня репозитория на Windows:

```powershell
python -I -S scripts/analyze_svd_third_package.py --root docs/svd_compression/results/third-local-2026-10-15 --destination third-recalculated
```

На Windows и Linux можно использовать отдельную программу переноса:

```text
python -I -S scripts/replay_svd_third_package_portable.py --root docs/svd_compression/results/third-local-2026-10-15 --destination third-portable-recalculated
```

Она сохраняет оригинал и временно нормализует только разделители `relative_path` в индексе `run.json`. Протокол, результаты процессов и ресурсы копируются без изменения байтов. Анализ выполняет та же зафиксированная программа; преобразование путей записывается в отдельный журнал. Числа, статусы и строки таблиц должны совпасть с опубликованными файлами `analysis/analysis.json`, `analysis/blocks.csv`, `analysis/comparisons.csv`. Совпадение содержания и байтов проверяется раздельно: переводы строк могут отличаться между ОС. Локальный пересчёт на Windows дал также побайтовое совпадение всех трёх файлов. Каталог назначения должен быть новым.

Для переноса достаточно опубликованных JSON и исходных файлов программы анализа; контрольные точки моделей и исходный путь локального архива не нужны. Графы и показатели CUDA Events не требуют доступной GPU для пересчёта.

## Ограничения

Один обученный seed 42, одна небольшая DigitsCNN, FP32/TorchScript и одно локальное устройство не определяют эффективность больших CNN и других сред исполнения. Прежние валидация и test уже использовались в разработке. Блоки в одном процессе отражают временной разброс этой серии, а не независимые повторы обучения. Данные GPU не подтверждают устойчивое ускорение; частоты, P-state и температура не устанавливают причину нестабильности.
