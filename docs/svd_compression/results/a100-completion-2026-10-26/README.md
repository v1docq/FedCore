# A100: завершение из полной M0, 26.10.2026

`raw/` содержит неизменённые свидетельства одного завершённого продолжения. Двадцать бинарных файлов остаются на A100; их SHA-256, размеры, время записи и тензорные ZIP-хранилища записаны в completion-file-inventory.json. Архив передачи не дублируется в Git; его контрольная сумма находится в export-receipt.json.

`inputs/` — отдельная побайтная копия опубликованного неуспешного parent report и его окружения; это исходные входы, а не результат нового запуска. `validation/` хранит подготовительные CPU-проверки и проверку сохранности. Первый installed-preflight.json зафиксировал нехватку вынесенных журналов в старом пути до CUDA; complete-parent-preflight.json подтверждает успех после создания отдельного полного parent-snapshot. Официальный test в подготовке не оценивался.

Пересчёт требует Python 3.10 и NumPy, без PyTorch, CUDA и повторного исполнения моделей. Новые каталоги вывода:

```powershell
python tools/analyze_completion.py raw C:/path/to/new-analysis --parent-report inputs/report.json
python tools/build_completion_report.py C:/path/to/new-analysis C:/path/to/new-report
```

MD/HTML располагаются в docs/svd_compression рядом с results, чтобы относительные ссылки работали. Расход — 3339,3260714150965 прежних секунд плюс полный внешний слот продолжения 151,8612541258335 секунды. Автоматических повторов нет. 5000 строк предсказаний перенесены из parent M0; 90 000 вычислены в продолжении. Выполнены ровно пять восстановлений по 200 обновлений, оценки шести артефактов на отложенном тесте и заранее ограниченные A/A; сравнений компактных моделей A/B нет из-за непрохождения A/A.

Манифест фиксирует байты всех опубликованных материалов; собственный хеш манифеста в него не включён. До открытия test зафиксированы шесть артефактов. Старые рабочие копии и каталоги результатов не переписывались.
