# Независимая проверка прерванной попытки

Проверяющий: согласованный `gpt-6.1-sol / xhigh`. Проверка выполнена чтением файлов, независимым пересчётом JSONL и SHA-256. Проверяющий не запускал тесты, ML, SSH или новые численные операции.

Подтверждены 3521 запись `baseline_update`, 11 записей завершения эпох и 78 шагов двенадцатой; 11 неполных батчей по 64 изображения дают суммарно 449984 предъявления. Снимков надзора 382, из них 173 с двумя сырыми GPU-строками; первое такое наблюдение — 130,534674879 с. У всех 173 причина отказа отсутствовала. Поиск, восстановление, оценки, NPZ/PT и пары времени отсутствуют.

Все 40 файлов исходного выгруженного манифеста совпали по SHA-256 и размеру. Все 325 файлов ML-пакета совпали с закреплённым манифестом. 1762 прежних файла подтверждаются серверной квитанцией; полный удалённый набор проверяющий повторно не читал. Арифметика общего интервала и ручного завершения проверена. В квитанции два собственных PID отсутствуют, один остался zombie с прежним временем создания; живого остатка по этим записям нет.

Прежнее положительное заключение по проверке GPU PID было ошибочным: `NoSuchProcess` нельзя было отбрасывать. Новая проверка отклоняет неподтверждённое сопоставление пространств PID, несколько сырых строк, исчезнувший или изменившийся процесс. Проверяющий нашёл обход публичного конструктора `GpuObservation`; он закрыт и дополнен восемью прямыми отрицательными случаями. Итоговый журнал показывает 46 успешных CPU-проверок.

Блокирующих замечаний к этим числам и CPU-модулю не осталось. Это заключение не подтверждает реальное подключение нового внешнего наблюдателя к A100: доверенное сопоставление PID хоста отсутствует. Новый вычислительный запуск не выполнялся и не разрешён прежней квитанцией.

После отдельного чтения `cv_independent_guard.py` и его CPU-проверок блокирующих замечаний в пределах объявленного API не найдено: поставщик обязателен до создания процесса, сырые GPU-строки проверяются первыми, неизвестные соответствия останавливают исполнение, сигналы ограничены собственными локальными PID и временем создания, более ранние внешние сроки сохраняются. Локальный журнал подтверждает 69 проверок с имитацией среды. Это не доказательство готовности к A100: наблюдатель хоста, ограниченное время ответа поставщика и внешний контроль времени жизни всего дерева ещё не подтверждены.
