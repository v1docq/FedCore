# Материалы прерванной попытки независимых M0

Основной [отчёт](../../INDEPENDENT_M0_A100.md) и [HTML](../../independent-m0-a100-report.html) фиксируют отсутствие сравнительного результата. Единственный GPU-запуск остановлен после 3521 шага исходного обучения; повторов нет. Кластерная работа затем явно остановлена владельцем.

- `raw` — неизменённая выгрузка и окончательные журналы внешнего наблюдателя; старый `report.json` со значением `started` сохранён как есть.
- `analysis/audit.json` — пересчитанные факты, включая итог `interrupted_infrastructure` и отсутствующие основные метрики.
- `analysis/reviewed-report.json` — проверенные данные графиков с происхождением и правилами обработки.
- `validation` — CPU-проверки, независимое заключение, сохранность рабочих копий, проверка HTML и квитанция остановки владельцем.
- `replay.py` — воспроизведение анализа без моделей, Torch, CUDA и CIFAR-10; не команда возобновления обучения.
- `manifest.json` — SHA-256 опубликованных материалов и отчётов; не удостоверяет неизмеренное качество методов.

Команды и старая защита в `raw/control` — исторические доказательства. Исправленный контракт и обёртка находятся в `fedcore/experiments/cv_independent_supervision.py` и `cv_independent_guard.py`. Они не подключают доверенного наблюдателя хоста автоматически и не разрешают новую попытку.

`validation/poststop-guard-checks.tar.gz` сохраняет точные байты шести файлов серверной CPU-проверки. Два прежних `__init__.py` имеют окончания строк рабочей Windows-копии; Git может нормализовать их при обычном получении исходников. Хеши квитанции относятся к этому архиву, а не к предположению о неизменности окончаний строк во всех Git-копиях.
