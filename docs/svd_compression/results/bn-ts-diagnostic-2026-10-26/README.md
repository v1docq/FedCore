# Диагностика BN/SGD и TorchScript на A100, 26.10.2026

Одна утверждённая попытка завершилась за 157,67475575581193 внешней секунды при пределе 1800 с. Прежний расход — 3491,18732554093 с; общий — 3648,862081296742 с из 14400. Повторов не было. Выполнены 200+200 обновлений SGD, 6 оценок на 5000 поисковых изображениях, 9 A/A и 3 допущенных A/B. Официальная тестовая выборка не оценивалась.

`raw/` — побайтный экспорт журналов, NPZ, паспортов и управляющих файлов. Шесть бинарных снимков, включая копию M0,, включая копию M0, остаются на A100; `diagnostic-file-inventory.json` хранит их SHA-256, размеры файлов и объёмы тензорных ZIP-хранилищ. Старые TorchScript не копируются и не меняются: их происхождение закреплено в `completion_admission.json` и прежнем опубликованном пакете. Это не новые оценки качества этих компактных моделей.

`analysis/` — независимый пересчёт NumPy/стандартной библиотекой, без исполнения моделей. `inputs/` — отдельная копия прежнего report и списка зависимостей; `validation/` — квитанция передачи и дополнительные проверки сохранности после запуска. Архив передачи не дублируется в Git. Историческая подготовительная квитанция в соседнем `bn-ts-diagnostic-preparation-2026-10-26` не меняется.

Для воспроизведения нужны Python 3.10 и NumPy 1.26.4. Из текущего каталога укажите новые выходные каталоги:

```powershell
python tools/analyze_bn_ts_diagnostic.py raw C:/path/to/new-analysis --completion-report inputs/report.json
python tools/build_bn_ts_report.py C:/path/to/new-analysis raw C:/path/to/new-report
```

Ожидается `completed`, 320 согласованных проверок, 400 SGD, 30 000 новых строк, 9 A/A и 3 A/B. Builder создаёт MD/HTML; при размещении рядом с `results` работают относительные ссылки. HTML самодостаточен: данные, графики и переключатели встроены, внешние библиотеки не нужны. Шесть NPZ качества содержат одинаковые row_ids/labels; прежний baseline NPZ — седьмой, это отдельный вход для проверки точного воспроизведения.

Манифест фиксирует байты всех опубликованных материалов и обоих итоговых отчётов; собственный хеш не включается. Размеры и SHA бинарных файлов из удалённого экспорта опубликованы как свидетельство, локальные байты весов не проверялись. Выводы относятся к одной M0 и одной последовательности; прежний сбой A/A не воспроизведён, преимущество эволюции и новый успех по независимому тесту не установлены.
