# Численные данные первого локального пакета

[Отчёт и выводы](../../LOCAL_PACKAGE.md).

- `protocol.json`: зафиксированные настройки, данные, исходники, расписание 132 сессий и правило выбора калибровки.
- `transforms.json`: все 27 преобразований, включая два отказа `preserve_nullspace`, ошибки слоёв и полное хранение.
- `timing.json`: все 132 сессии и 165 000 индивидуальных замеров времени, включая 33 непригодные сессии; отдельно результаты 660 блоков пропускной способности.
- `recovery.json`: десять непрерывных кривых, состояния 0/100/400, ровно 4000 обновлений и 2000 обучающих вызовов учителя.
- `analysis/`: пересчитанные сравнения и четыре CSV. Времена сравниваются внутри полных допущенных пар, состояния восстановления — с плотным контролем по той же цели и на том же шаге.
- `processes/`: ресурсы всех 143 научных процессов. Бинарные модели и журналы стандартного вывода остаются в локальном архиве.
- `ledger-scientific.json`: журнал непосредственно после научной серии; его SHA используется в `implementer-final-audit.json`.
- `ledger.json`: тот же набор попыток с отдельным консервативным резервом на итоговые проверки и публикацию.
- `validation.json`, `independent-review.json`, `publication-review.json`: проверки кода, научных результатов и опубликованных копий.
- `publication-manifest.json`: исходные и опубликованные SHA256; для каждого JSON также проверена неизменность численной структуры.

Здесь находятся переносимые копии: абсолютные локальные пути заменены относительными обозначениями архива и окружения. Хеш зафиксированного протокола и входных файлов относится к исходному локальному архиву; хеш каждого опубликованного файла указан отдельно. Это разные объекты проверки.

Предыдущая проверочная выборка уже изучалась и здесь используется для разработки. Три блока времени и один обученный seed не устанавливают общее аппаратное или статистическое преимущество. Вызовы внутри сессии не являются независимыми повторами. Время восстановленных графов не измерялось; их экспорт проверяет численное совпадение.

Для пересчёта таблиц бинарные веса не нужны:

```powershell
python scripts/analyze_svd_local_package.py --input docs/svd_compression/results/local-2026-10-14 --output local-package-analysis
```

Повторное исполнение моделей требует локальных бинарных файлов. Исторические данные от 13 октября не изменены.
