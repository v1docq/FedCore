Сколько времени занимает сжатая модель после восстановления?

Четыре сохранённые CNN после 400 восстановительных обновлений с CE сравниваются с плотной моделью после 400 обновлений продолжения. Отдельно проверяются исторический AFM и стоимость двух факторов Conv. Все показатели времени получены на Ryzen 9 5950X и RTX 4080 в FP32 и TorchScript.

Главные выводы

На CPU при пакете 64 восстановленные Conv+Linear дают отношения времени 1,08–1,10×, исторический AFM — 1,29×. Это локальные оценки пилота: один CPU64-контроль имеет отношение 0,586, поэтому стабильность эффекта требует подтверждения. При пакете 1 восстановленные варианты медленнее плотной модели. В крупных синтетических Conv на CPU наблюдались отношения 1,91–3,96× к плотному слою с тем же весом.

Рейтинг GPU не установлен. Даже одинаковый плотный граф даёт диапазон парных отношений 0,478–1,872 при пакете 1 и 0,510–1,021 при пакете 64. Успешный допуск по нагрузке не гарантирует стационарность времени внутри сессии. Все 24 GPU-трассы не содержат событий ядер; причины нестабильности и точная стоимость ядер остаются открытыми.

583 из 584 сессий допущены; для сравнений пригодны 267 из 268 полных блоков. Одна тройка синтетического Conv исключена целиком, без повторного запуска.

Отношение времени — Tэталон/Tкандидат; для пропускной способности — наоборот. Показана медиана парных блоков. Усы — условный интервал медианы, когда хватает блоков; без него — наблюдавшийся диапазон.

Полная модель

Контроль для восстановленных CNN — плотная CE400. Исторический AFM сравнивается со своим исходным плотным графом.

Один и тот же вес: факторы или плотный Conv?

Здесь эталон — плотный слой с весом, собранным из факторов. Приближение функции совпадает; меняется способ исполнения. Для каждой нагрузки предусмотрено три полные тройки представлений.

Три крупных Conv — синтетические нагрузки с заранее заданными рангами. Их скорость не является результатом по качеству большой обученной CNN. Для трёх блоков приведён диапазон без 95%-го интервала.

Контроль измерительного тракта

Один и тот же плотный граф измеряется дважды, в пяти парах на режим. Отклонение отношений от 1 показывает разброс измерений. Контроль не доказывает независимость и стационарность всех последовательных измерений.

Что означают эти результаты

Меньшее хранение и число MAC не гарантируют меньшую задержку. Сравнивайте завершённый вызов, полный путь с передачей данных и пропускную способность отдельно. CUDA Events могут включать промежутки между запусками операторов с CPU; профили оператора не подставляются вместо обычного времени.

Качество 97,03% на валидации взято из первой серии: одна обученная исходная CNN, прежние данные разработки. Вторая серия добавляет измерение исполнения. Интервалы относятся к отдельным ячейкам времени при предположениях независимости и стационарности блоков, с учётом допуска полных пар; общей гарантии для всей таблицы нет.

Первую попытку V1 остановили из-за загрузки исторических файлов по пути с кириллицей: 39 успешных сессий, четыре ошибки и одна незапущенная попытка сохранены отдельно. Их время перенесено в общий учёт; в числах этой страницы используются свежие результаты V2.
