# Проверки смешанной точности Dobi-SVD

Дата: 12.10.2026. Подэтап #135, ветка `svd_compression`, PR #140, поверх `fd18b67540853ae39ade283d9a3ea980f303cd48`. [Реализация и ограничения](IMPLEMENTATION_DOBI_REMAPPING.md), [независимая проверка](REVIEW_DOBI_REMAPPING.md).

## Окончательный результат

Windows, Python 3.10.0, PyTorch 2.2.0+cu121. Обучение границ и IPCA выполнялись на CPU. Короткая проверка вычислений и градиента по входу выполнялась на NVIDIA GeForce RTX 4080, CUDA 12.1. Зависимости, внешние данные и модели не загружались.

|---|---|
| Общий набор: refactoring, PETRA, низкоранговые и статистические проверки | **1483 passed, 3 skipped**, 279,02 с |
| Новый набор remapping внутри общего прогона | **147 проверок**: 77 реализации и 70 независимых |
| Отдельный независимый прогон | **70 passed**, 12,92 с |
| Wheel, sdist, повторная сборка из sdist, установка и публичный API вне исходного дерева | **1 passed**, 86,18 с |

| Демонстрации через публичный API | **8 сценариев**, 16 обновлений Adam, сохранение, загрузка и фиксированный TorchScript |

Три пропуска требуют отдельного окружения современного FEDOT/IndustrialTS и второго интерпретатора сжатия. CUDA-проверка входит также в общий прогон; её отдельный результат не увеличивает число уникальных тестов. Предупреждения зависимостей и завершающего обработчика `pyreadline3` не изменили код возврата 0.

Независимые проверки покрывают аналитический эталон без повторного SVD, градиент байтового штрафа, обе ориентации прямоугольных матриц, полный/нулевой ранги, повреждение дескрипторов и состояния, собственное хранилище частей формата, общие хранилища, отказ до присваивания, очистку после ошибки и повторный экспорт. Четыре найденные группы нарушений исправлены до общего окончательного прогона.

## Малые демонстрации

Все размеры ниже относятся ко всем хранимым тензорам модели, включая неизменённый второй слой, смещения, коды и шкалы. Размеры файлов контрольной точки и TorchScript записаны отдельно.

| Сценарий | Ранг | Байты тензоров | MSE всей модели на отложенном искусственном входе |
|---|---:|---:|---:|
| Широкий вес, исходные факторы | 19 | 6868 | 0,0142817 |
| Широкий вес, int8 + float16 | 19 | 2764 | 0,0143365 |
| Широкий вес, int8 + bfloat16 | 19 | 2764 | 0,0143469 |
| Вес `W[48,32]`, int8 + float16 | 19 | 3148 | 0,00966059 |
| Квадратный вес, int8 | 19 | 2156 | 0,00504361 |
| Полный ранг, remapping | 32 | 4116 | 0,00000433970 |
| Нулевой ранг, только смещение | 0 | 788 | 0,0980610 |
| Широкий вес, предел 2664 байта | 18 | 2660 | 0,0159525 |

Исходная широкая модель содержит 6932 байта тензоров. При ранге 19 дополнительная локальная калибровочная MSE remapping составляет около `1,29e-5`, ошибка усечения — `0,0268225`. При полном ранге ошибка усечения равна нулю, но ошибка remapping ненулевая. При ограничении 2664 байта алгоритм уменьшает ранг с 19 до 18; в отчёте записана экономия 104 байта.

В квадратном случае суммарная локальная MSE немного меньше ошибки одного усечения из-за перекрёстного члена. Ошибки нельзя складывать как независимые неотрицательные вклады. Эти примеры проверяют механизм; они не подтверждают качество LLM или выигрыш по скорости.

```powershell
python -m pytest -q tests/refactoring tests/petra tests/unit/algorithm/low_rank tests/unit/low_rank/test_statistical_profiles.py tests/unit/low_rank/test_statistical_collectors.py --ignore=tests/refactoring/test_core_packaging.py

```

На Windows используются разрешённые `TEMP`, `TMP` и `--basetemp`. Общий набор выполнялся с четырьмя потоками CPU, демонстрация — с двумя и seed 135. Полные XML, журналы и артефакты сохранены в `C:/Users/user/Documents/Codex/FedCore-Dobi-135-2026-10-12`. [Численный отчёт](dobi-remapping-results.json) содержит исходные результаты, SHA256 файлов и 15 канонических исходников Git с переводами строк LF. Их соответствие проверяется перед коммитом.

Локальный результат не заменяет CI опубликованного коммита: его состояние фиксируется отдельно в PR #140. Проверенный формат использует собственное симметричное int8-квантование, отличающееся от авторского bitsandbytes. Произвольное изменение точности родительской модели и скомпилированного артефакта не покрыто; проверки входа могут исчезать при трассировке. Декодирование создаёт временные факторы; размер хранения не равен пику памяти и не доказывает ускорения.
