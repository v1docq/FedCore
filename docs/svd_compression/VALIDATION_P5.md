# Проверки P5

Окружение: Windows, Python 3.10.0, PyTorch 2.2.0+cu121; все вычисления выполнялись на CPU. Зависимости не менялись. Загрузки моделей и данных отключены; внешний кластер и OpenResearch не использовались.

## Автоматические проверки

Общий окончательный прогон зафиксированной версии кода: **1336 passed, 3 skipped**, 514,17 с. Три пропуска относятся к проверкам, требующим отдельного окружения современного FEDOT. Набор выполнялся целиком после исправлений, включая локальные Dask-проверки.

Состав нового набора: 62 проверки SliceGPT, 20 LightFormer, 112 LRT, шесть общего интерфейса и 26 независимых проверок. Все **226 проверок P5** входят в общий прогон. Проверяются математические эталоны, градиенты, действительные шаги оптимизатора, формы, уникальные хранилища, бюджеты, сохранение RNG/источника и отрицательные случаи.

Wheel и sdist собраны; wheel повторно собран из sdist, установлен без зависимостей в отдельный каталог и проверен вне исходного дерева. Все три P5-профиля вызываются через публичный `LowRankModel.build_architecture` установленного пакета. Итог: **1 passed**, 89,94 с. Дополнительно прошли проверка секретов examples и `git diff --check`.

Независимый набор: **26 passed**, 24,00 с. [Отчёт](REVIEW_P5.md) описывает три исправленные группы дефектов: допуск размеров до выделения памяти, незаявленные связи параметров/буферов и подмену методов/обработчиков при сохранении. Подтверждённых открытых блокирующих замечаний в проверенной области нет.

## Семь демонстраций

Каждый сценарий прошёл сохранение, точную загрузку логитов и TorchScript на фиксированном входе. Калибровочные и проверочные токены различаются. Для четырёх обучаемых сценариев выполнено **24 обновления Adam** через существующий `train_model`; отчёты содержат роли и хеши данных, значения потерь, градиенты и состояние оптимизатора по шагам.

| Сценарий | Уникальные параметры | Байты постоянных тензоров | Ошибка логитов относительно источника, MSE | Шаги обучения |
|---|---:|---:|---:|---:|
| SliceGPT, полный поворот | 1225 | 12496 | $1{,}70\cdot10^{-29}$ | 0 |
| SliceGPT, ширины 6/6/6/6/6 | 943 | 9120 | 0,375 | 0 |
| SliceGPT, ширины 6/6/5/5/4 | 855 | 8056 | 2,255 | 0 |
| LightFormer, общие группы encoder | 2445 | 20440 | Не сравнивается после обучения | 6 |
| LightFormer, расширение с общими decoder-группами | 1509 | 12928 | Не сравнивается после обучения | 6 |
| LRT, факторизованный | 741 | 6872 | Нет готового источника | 6 |
| LRT, плотный контроль | 821 | 7512 | Нет готового источника | 6 |

Исходный SliceGPT содержит 1265 параметров и 12816 байт постоянных тензоров. При полном повороте 40 коэффициентов нормировок включаются в веса потребителей. Максимальная ошибка логитов полного поворота составляет $1{,}60\cdot10^{-14}$. Уменьшение ширины уже приближённое: меньший размер может сопровождаться большей ошибкой. KV-кэш сохраняет исходные размеры голов, что проверено отдельно в причинном продолжении.

Исходный LightFormer содержит 4029 уникальных параметров, глубину encoder/decoder 2/3. Две демонстрации используют глубину 6/3 и 6/2 при фактическом разделении полных блоков. Число применений Linear составляет соответственно 133 и 113; число уникальных параметров не заменяет число вычислений.

У LRT и плотного контроля совпадают данные, перемешивание, шесть обновлений и параметры Adam. Начальные функции различаются, хотя объявленное семейство инициализации совпадает. Проверочная перекрёстная энтропия после короткого обучения равна соответственно 3,091 и 3,129. Эти числа на искусственных токенах не устанавливают превосходство метода; статистическая серия по значениям seed и реальным задачам не проводилась.

## Воспроизведение и границы

```powershell
python -m pytest -q tests/refactoring tests/petra tests/unit/algorithm/low_rank tests/unit/low_rank/test_statistical_profiles.py tests/unit/low_rank/test_statistical_collectors.py --ignore=tests/refactoring/test_core_packaging.py
python -m pytest -q tests/refactoring/test_core_packaging.py
python -m examples.low_rank_ann.p5_profiles --output local-p5-demo
python scripts/check_example_secrets.py examples
```

Общий прогон использует четыре потока CPU, демонстрации — два. Для Windows заданы `TEMP`, `TMP` и `--basetemp` внутри разрешённого каталога. Dask-проверки общего набора требуют локальных процессов и сетевых соединений между ними. Известные предупреждения зависимостей, трассировки и завершающего обработчика `pyreadline3` не меняют успешный код завершения.

Поддержаны только явно заданные ограниченные графы на CPU float32/float64. Большие модели, ASR/CER/beam search, измерения задержки/RSS и аппаратное преимущество не воспроизведены. Фиксированная трассировка не сертифицирует динамические длины, маски и режимы кэша. P5 не подключён к конфигурациям PETRA и внешнему контракту v3. [Полные границы реализации](IMPLEMENTATION_P5.md). Issues остаются открытыми до проверки и принятия изменений; поздний ASR-подэтап #139 и remapping #135 сохраняются отдельно.
