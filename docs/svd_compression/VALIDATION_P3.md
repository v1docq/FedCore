## Что проверено

- Шесть матриц ESPACE сверены с явными суммами по наблюдениям. Неопределённый пример `diag(1,-100)` отличает алгебраический выбор `eigh` от SVD. Отдельный эталон первого шага Adam проверяет обучение полной W при фиксированном P и последующую компактную сборку.
- PELA проверяется по независимым градиентам двух норм и двух регуляризаторов. Учитель заморожен; карта блоков, память учителя и состояние оптимизатора проверяются до обучения. PETRA использует только train и выполняет точное число обновлений.
- Кандидаты LASER начинаются с одной исходной модели. Проверены сохранение плотного размера, отдельная экономичная факторизация, совпадение функции выбранного вмешательства и учёт буферов.
- FLAT V/O и MoDeGPT имеют различимые численные цели. Полный ранг сохраняет функцию; усечение изменяет реальные размеры проекций и кэша. Совместная цель GQA обозначена как расширение.
- Attention сверяется с отдельным расчётом по головам и токенам: нестандартная карта GQA, исходный масштаб логитов, RoPE, маски, полностью запрещённые строки, заполнение кэша и продолжение. Квадратичная память проверяется до прямого прохода.
- Gate/Up выбирают одни и те же реальные каналы после исходной активации. Down сверяется с независимым `lstsq` на той же фиксированной матрице, включая вырожденный случай. Произвольный поворот через нелинейность не допускается.
- CTR проверяется при ненулевых средних: сумма вкладов, аффинная поправка и декодированные взаимодействия. Частотные и равномерные наблюдения разделены. Нелинейный MLP проходит реальное восстановление.
- Проверены фактический уникальный размер параметров и буферов, отказ при превышении бюджета на один байт, сохранение общих параметров/буферов и исходной модели. Повреждённые координаты attention и фиксированные геометрические буферы отклоняются при загрузке.
- Шесть связных профилей проходят публичный `LowRankModel.compress_profile`, checkpoint и TorchScript. Установленный wheel выполняет ESPACE, V/O и MLP вне исходного дерева. Внешний контракт v3 явно отклоняет все новые описания; прежние регрессии v1/v2/v3 проходят.

## Воспроизводимость

```powershell
python -m pytest -q tests/refactoring tests/petra tests/unit/algorithm/low_rank tests/unit/low_rank/test_statistical_profiles.py tests/unit/low_rank/test_statistical_collectors.py --ignore=tests/refactoring/test_core_packaging.py
python -m pytest -q tests/refactoring/test_core_packaging.py
python -m examples.low_rank_ann.p3_profiles --output local-p3-demo
python scripts/check_example_secrets.py examples
```

Для локальной Windows-песочницы следует задать `--basetemp` внутри разрешённого рабочего каталога. Набор использует четыре потока CPU. Демонстрация фиксирует seed `20261012`; 18 обновлений восстановления распределены между девятью сценариями. Сводные размеры, ошибки на независимых искусственных данных и хеши исходников сохранены в [p3-mechanism-results.json](p3-mechanism-results.json).

TorchScript проверен для объявленной формы единственного входа. Attention использует резервный путь трассировки; проверки Python в нём становятся константами. Динамические формы, дополнительный интерфейс масок и передача KV-кэша через экспортированный артефакт не заявлены. CTR экспортируется через явное представление с двумя выходами: линейный результат и взаимодействия.

Известные предупреждения зависимостей, трассировки и завершающего обработчика `pyreadline3` не меняют код завершения 0. Качество больших LLM/ViT, реальные PPL, задержка и ресурсное преимущество этими малыми проверками не доказаны. Поддержанные границы и версии источников перечислены в [IMPLEMENTATION_P3.md](IMPLEMENTATION_P3.md).
