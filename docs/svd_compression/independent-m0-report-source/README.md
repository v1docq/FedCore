# Исходные материалы HTML-отчёта

В Git сохранены авторский текст, стили, проверенные данные и скрипт сборки. Копия сторонней инфраструктуры Data остаётся только в локальной рабочей папке и не включается в изменения FedCore. Автономный `../independent-m0-a100-report.html` открывается без плагинов и CDN. Независимый анализ данных выполняет `../results/independent-m0-a100-2026-10-30/replay.py` на стандартном Python.

Для повторной сборки нужен установленный Data plugin той же версии и совместимый Node. Из-за обработки путей в установленном сборщике на Windows эта версия отчёта собрана в WSL; защищённые файлы плагина и приложения не изменялись. Проверенная версия Node и контрольные суммы находятся в `validation/report-linux-node.json`, результат визуальной проверки — в `validation/report-qa.json` каталога пакета.

```text
node rebuild-report.mjs ABSOLUTE_DATA_PLUGIN_ROOT ABSOLUTE_NEW_BUILD_DIRECTORY
```

Скрипт создаёт новую временную рабочую папку официальным средством, восстанавливает тот же идентификатор отчёта, переносит только авторские файлы и данные и требует прежний хеш инфраструктуры. Численные эксперименты не запускаются. Старую папку сборки передавать нельзя; её содержимое сохраняется.
