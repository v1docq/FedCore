# Проверка подготовки Sparse/CV-пилота

Дата: 21.10.2026. [Реализация](IMPLEMENTATION_SPARSE_CV.md), [план и бюджет](SPARSE_CV_A100_PLAN.md), [исходные журналы](results/sparse-cv-preparation-2026-10-21/manifest.json).

Подготовка прошла локальную CPU-проверку. GPU-пилот ещё не запускался: пользователь сообщил, что отдельно подтвердит освобождение A100. Поэтому качество на CIFAR-10, ускорение и преимущество эволюционного поиска пока не оценены.

Общая регрессия завершилась до последней узкой правки `cv_sparse_runtime.py`, `cv_sparse_pilot.py` и её тестов. Эта правка отдельно проверена 41 тестом; общий CI окончательного коммита должен проверить весь набор повторно. Числа общей и целевой проверок не складываются: они частично пересекаются. Две проверки надзора, пропущенные на Windows, выполнены на Linux отдельно.

В ранних запусках были обнаружены и исправлены реальные дефекты: неготовый жизненный цикл тестового фасада; захват функций G3 до подмены в проверках; слишком строгий отказ при пустых служебных словарях обработчиков тензоров после сериализации. Исходные неуспешные журналы сохранены рядом с успешными. Дополнительно закрыты замечания к непрозрачным атрибутам, порядку модулей, ранней проверке checkpoint, таймеру надзора и завершению собственной группы процессов.

Перед открытием официального test теперь заново проверяются контрольные суммы всех выбранных файлов, полнота исходного обучения и восстановления. `CheckpointMismatch`, `RepresentationMismatch`, другие структурные и численные нарушения останавливают пилот с сохранением исходной причины и учтённой попытки. Продолжение разрешено только для точно объявленных ресурсных отказов `ResourceLimitExceeded` и `EvaluationDeadline`.

Локальная проверка использует отдельную CPU-среду без изменения исходных окружений. Версии установленных дистрибутивов сохранены в `local-environment-packages.json`: `pip freeze` не смог разрешить путь редактируемой установки через рабочее дерево Git на другом диске Windows. Это ограничение сбора метаданных; `pip check` и установленный пакет проверены самостоятельно. Для отдельной среды A100 сохранён обычный `remote-environment-freeze.txt`; перед запуском туда будет установлен окончательный wheel с паспортом исходников.

Допуск ограничен именованным инженерным пилотом на одной A100 40 ГБ. Следующие обязательные границы — успешный CI, проверка окончательного установленного пакета на Linux, готовые официальные данные, явное сообщение пользователя об освобождении GPU и повторная проверка отсутствия чужих вычислительных процессов. Общий предел первого пилота остаётся 4 GPU-часа; автоматического повтора или возобновления прежних серий нет.
