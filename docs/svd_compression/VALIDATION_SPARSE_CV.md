Общая локальная регрессия завершилась до последней узкой правки `cv_sparse_runtime.py`, `cv_sparse_pilot.py` и её тестов. Эта правка отдельно проверена 41 тестом; [общий CI окончательного коммита кода](https://github.com/v1docq/FedCore/actions/runs/39617339533) затем успешно проверил весь набор. Числа общей и целевой проверок не складываются: они частично пересекаются. Две проверки надзора, пропущенные на Windows, выполнены на Linux отдельно.

В ранних запусках были обнаружены и исправлены реальные дефекты: неготовый жизненный цикл тестового фасада; захват функций G3 до подмены в проверках; слишком строгий отказ при пустых служебных словарях обработчиков тензоров после сериализации. Исходные неуспешные журналы сохранены рядом с успешными. Дополнительно закрыты замечания к непрозрачным атрибутам, порядку модулей, ранней проверке checkpoint, таймеру надзора и завершению собственной группы процессов.

Перед открытием официального test теперь заново проверяются контрольные суммы всех выбранных файлов, полнота исходного обучения и восстановления. `CheckpointMismatch`, `RepresentationMismatch`, другие структурные и численные нарушения останавливают пилот с сохранением исходной причины и учтённой попытки. Продолжение разрешено только для точно объявленных ресурсных отказов `ResourceLimitExceeded` и `EvaluationDeadline`.

Локальная проверка использует отдельную CPU-среду без изменения исходных окружений. Версии установленных дистрибутивов сохранены в `local-environment-packages.json`: `pip freeze` не смог разрешить путь редактируемой установки через рабочее дерево Git на другом диске Windows. Это ограничение сбора метаданных; `pip check` и установленный пакет проверены самостоятельно. Для отдельной среды A100 сохранён обычный `remote-environment-freeze.txt`.

Окончательный wheel установлен в отдельной среде A100 и проверен 111 CPU-тестами. Паспорт связывает коммит `3bc0825a9ef1bcd0ac8eb0181b6d5314b57ebb8d`, SHA-256 wheel `26fcf56c64c8b68dd6aa00879b16dc926193ed7f4159a01fc3b8e42e069fb913`, хеш протокола `81e30bb6853080e2b6fedf966fc19f44cf717a8192988df5c3db552a3dd12010` и 313 файлов FedCore. Эти проверки не открывали CUDA-контекст. Последующие изменения документации не меняют зафиксированный код пакета.

Первоначальный подготовительный вызов зафиксировал `missing_data`, пока официальный архив ещё загружался. После завершения загрузки отдельный повтор только подготовительного режима дал `prepared`: все исходные файлы доступны, 313 файлов пакета совпадают с паспортом, каталог результатов не создан. Оба состояния сохранены в `final-install-check.json` и `prepared-admission.json`; это не повтор эксперимента. Официальный test не оценивался.

Допуск ограничен именованным инженерным пилотом на одной A100 40 ГБ. Команда и ограничения сохранены в `launch-packet.json` со статусом `not_started`. Перед GPU остаются явное сообщение пользователя об освобождении GPU и повторная проверка отсутствия чужих вычислительных процессов. Общий предел первого пилота остаётся 4 GPU-часа; автоматического повтора или возобновления прежних серий нет.
